POLSKI – PWA-Dateien

Enthalten:
- index.html: Sprachtrainer
- manifest.webmanifest: Installationsdaten
- service-worker.js: Offline-Grundfunktion
- icon.svg, icon-192.png, icon-512.png: App-Symbole

GitHub Pages:
1. Alle Dateien direkt in das Stammverzeichnis des Repositorys `polski` hochladen.
2. Repository > Settings > Pages öffnen.
3. Bei Build and deployment: Deploy from a branch wählen.
4. Branch `main`, Ordner `/(root)` auswählen und Save.
5. Nach dem Veröffentlichen https://ptrcknggt.github.io/polski/ öffnen.

Der Lernfortschritt wird auf dem Gerät im Browserprofil gespeichert. Beim ersten Wechsel von der lokalen HTML-Datei zur veröffentlichten HTTPS-App beginnt der Fortschritt in der Regel neu; den alten Lernstand kann man vorher über „Profil > Lernstand exportieren“ sichern.
